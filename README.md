# Обучающее приложение для адаптации новых сотрудников

Одностраничное веб-приложение: материалы для изучения, тесты и интерактивные задания.
Без сборки и зависимостей — один HTML-файл и папка с картинками.

## Структура

```
├── index.html   — приложение целиком (HTML + CSS + JS)
├── assets/      — изображения
└── README.md
```

Прогресс пользователя хранится в `localStorage` браузера, серверная часть не нужна.

## Запуск

Локально:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

Публикация: Settings → Pages → Source `Deploy from a branch`, ветка `main`, папка `/ (root)`.

## Форма обратной связи

Кнопка в правом нижнем углу открывает форму с полями «ФИО» и «Вопрос».
Сейчас записи сохраняются только в браузере пользователя и доступны для копирования.

Чтобы подключить доставку, укажите адрес приёмника в `index.html`:

```js
const ASK_ENDPOINT = '';   // URL приёмника: webhook формы, бот, почтовый сервис
```

Форма отправит `POST` с JSON `{ name, question, sentAt }`.

> На GitHub Pages нет серверной части, поэтому нужен внешний приёмник.
> Не размещайте в файле токены и ключи — исходный код страницы виден всем.

## Файлы документов

Исходные документы в репозиторий не выкладываются, они перечислены в `.gitignore`.
Чтобы включить их скачивание: положите файлы в `assets/docs/` с именами из ссылок в `index.html`,
уберите строку `assets/docs/` из `.gitignore` и удалите блок `db-warn` из разметки.

## Правка текстов

Тексты документов в приложении приведены дословно. Пояснения помощника вынесены в отдельные
блоки и частью документов не являются.

При изменении исходных документов правки нужно перенести в разметку `index.html`
и в банк вопросов (`QUIZ` в конце файла).
