# Приложение адаптации

Обучающее веб-приложение для адаптации новых сотрудников Управления HR.
Цифровой наставник **Ал** проводит сотрудника по трём документам и готовит к устной сдаче материала старшему сотруднику.

## Что внутри

| Раздел | Содержание |
|---|---|
| **Регламент** | Регламент о правилах работы внутри Управления HR (приказ №97 от 01.02.2025) – 8 разделов |
| **Культура** | Корпоративная культура компании: миссия, ценности, стратегия, 21 компетенция, лидерство, делегирование, грейды |
| **Симуляции** | Правила игр ассессмента: общая база, Business Cats (LTD RT / Team / CORP), Грузовики (LTD RT / Team), Civilization IV (Single / Duel / 3×3) |
| **Тренажёр** | 118 карточек для проговаривания вслух, с раздельными колодами по документам |
| **Путь адаптации** | Порядок освоения и чек-лист из 24 пунктов |
| **База данных** | Скачивание исходных документов (на главной странице) |
| **FAQ** | 15 частых вопросов по программе адаптации (на главной странице) |

## Структура

```
baza/
├── index.html   – всё приложение (HTML + CSS + JS, без сборки и зависимостей)
├── assets/
│   ├── *.jpg    – иллюстрации из документов (таблицы уровней, алгоритмы, схемы)
│   ├── logo-alabuga-mark.png / logo-alabuga-full.png – логотип
│   └── docs/    – исходные документы для скачивания (82 МБ)
└── README.md
```

> Папка `assets/docs` весит 82 МБ. Это укладывается в лимиты GitHub, но клонирование
> репозитория станет заметно тяжелее. Если это мешает, документы можно вынести
> на внешнее хранилище и заменить ссылки в разделе «База данных».

Прогресс сотрудника хранится в `localStorage` его браузера – сервер не нужен.

## Запуск

Локально – открыть `index.html` в браузере.

На GitHub Pages: Settings → Pages → Source: ветка и папка `/baza`.

## Форма вопроса наставнику

Кнопка с аватаром Ала внизу справа открывает окно «Привет, чем могу помочь?»: сотрудник вводит ФИО и вопрос.

Сейчас вопросы **сохраняются в браузере сотрудника** и доступны для копирования – канал доставки не подключён.
Чтобы вопросы приходили в мессенджер или на почту, укажите адрес приёма в `index.html`:

```js
const ASK_ENDPOINT = '';   // ← сюда URL приёмника (webhook формы, бот, почтовый сервис)
```

Форма отправит `POST` с JSON `{ name, question, sentAt }`.

> На GitHub Pages нет серверной части, поэтому нужен внешний приёмник (сервис форм или бот).
> Не вставляйте в этот файл токен бота – он будет виден всем в исходном коде страницы.

## Важно о текстах

Тексты регламента, корпоративной культуры и правил игр приведены **дословно по исходным документам** – сотрудники сдают их практически слово в слово.
Комментарии наставника Ала оформлены отдельными голубыми блоками и не являются частью документов.

При изменении исходных документов правки нужно перенести в `index.html` и в карточки тренажёра.
